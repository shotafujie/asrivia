# qwen-context: Qwen3-ASR の辞書(context)効果

`words.json` の登録語を Qwen3-ASR の context(システムプロンプト)に渡したとき、
登録語が出やすくなるか・副作用が出ないかを、context なしの基準と比べる。

## 仮説と反証条件

- 仮説: 登録語を context に渡すと、登録語が正しく認識されやすくなる
- 反証条件(いずれか1つで不採用)
  1. 登録語の再現率が上がらない
  2. 全発話の CER が基準より悪化する
  3. 1発話あたりのレイテンシが大きく増える

## 条件

- 入力: koepus コーパスの `status='verified'`(人手修正済み)全165発話 / 9.9分 / 16kHz mono 16bit
- 辞書: 正解テキスト中の固有名詞・専門語 11語 + 既存 `words.json` の 2語(コーパスに出ない語、誤挿入の確認用)= 13語。**評価前に固定**
  - 固有名詞(人名を含む)をリポジトリに入れないため、辞書は `local/dict.txt`(gitignore)に置き、`--dict` で渡す
- 基準(base): 同じ `Session` を context なしで呼ぶ
- 対象(ctx): `QwenASRBackend.transcribe`(context + 漏れガード。再認識の時間も含む)
- 環境: Apple M4 Max / 128GB / macOS 27.0 / `Qwen/Qwen3-ASR-1.7B` / language=Japanese
- 計測: 発話ごとに2条件をシード固定のランダム順で実行、ウォームアップ2発話
- 正規化: NFKC・小文字化・句読点/記号/空白を除去してから CER と語の照合を行う

## 再実行

```bash
uv run python benchmarks/qwen-context/run.py --dict benchmarks/qwen-context/local/dict.txt
```

発話ごとの結果(`results.jsonl`)と語ごとの表(`per_word.json`)は `local/` に出る(発話内容を含むためコミットしない)。

## 結果(2026-09-29)

| 条件 | 登録語再現 | 誤挿入 | CER | レイテンシ中央値 | p90 |
|------|-----------|--------|-----|----------------|-----|
| base(context なし) | 2/13 | 0 | 20.8% | 0.516s | 0.982s |
| ctx(漏れガードなし・初回) | 9/13 | 14 | 22.5% | 0.608s ※ | 1.174s ※ |
| ctx(漏れガード: 再認識) | 8/13 | 2 | 20.3% | 0.532s | 1.056s |
| **ctx(漏れガード: 区間を破棄・現行)** | **8/13** | **2** | **20.3%** | **0.725s ※2** | **1.929s ※2** |

※ 初回は別セッションでの測定。この回の base は 0.571s / p90 1.079s。
※2 別セッションでの測定。この回の base は 0.693s / p90 1.639s(マシンの状態で全体が遅い回。対基準 +4.7%)。

- 漏れガードなしの悪化(誤挿入14件のうち12件、CER 悪化の大半)は1発話(1.1秒)で起きた。
  モデルが context の単語リスト全体をそのまま出力した。漏れガードはこの1件で発動し、context なしの結果に戻した(そのためこの発話の登録語は拾えず 9→8)
- 残りの誤挿入2件: 1件は正解テキストとの表記ゆれ(長音の有無)で認識自体は正しい。1件は 0.8秒の発話に登録語が出た本物の誤り
- 判定: 反証条件 1〜3 のいずれも当たらない(漏れガード付き)。採用
- 2026-09-29 追記: 実機(PiP で常時認識)では、無音・雑音の短い区間(0.6〜0.9秒が中心)で漏れが多発した
  (字幕93件に対し漏れ検出52回)。再認識は漏れのたびに認識時間を倍にしキューを詰まらせるため、
  漏れた区間は捨てる方式に変えた(SPEC-006 廃番 → SPEC-024)。このコーパスは人手確認済みの発話だけで
  無音・雑音区間を含まないため、この差はベンチでは再現しない(漏れ1件の扱いが変わるだけで CER 20.30% → 20.33%)
- 限界: 登録語を含む(発話, 語)は13組しかなく、再現率の差は小標本。辞書は正解テキストから選んだため、「その語を登録していた場合」の効果を測っている
