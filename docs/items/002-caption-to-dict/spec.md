# 仕様: 確定字幕から辞書登録を開く

## 背景

誤認識を見た瞬間に辞書登録したい。これまでは 📚 ボタンで空の辞書ウィンドウを開き、
語を打ち直す必要があった。確定字幕の行を右クリックすると、その行の文を単語欄に入れた状態で
辞書ウィンドウを開けるようにする(辞書が効く hf / qwen バックエンドのみ)。

tk の Label は文字の部分選択ができないため、行の全文を入れて全選択し、利用者が語だけに削る。

## 仕様

- **SPEC-009** 確定字幕の登録文は、その発話の現在の表示テキスト(インライン編集後の文を含み、翻訳は含まない)である
- **SPEC-010** 存在しない発話を指定したとき、登録文は無い(None)
- **SPEC-011** 辞書ウィンドウが開いていないときに開く操作をすると、辞書ウィンドウを1つ作る
- **SPEC-012** 辞書ウィンドウが開いているときに開く操作をすると、新しいウィンドウを作らず既存のウィンドウを使う
- **SPEC-013** 辞書ウィンドウを閉じた後に開く操作をすると、新しい辞書ウィンドウを作る
- **SPEC-014** 登録文を指定して開いたとき、単語欄はその登録文だけになり(元の入力は置き換える)、全体が選択された状態になる
- **SPEC-015** 登録文を指定せずに開いたとき(📚 ボタン)、単語欄の入力は変わらない

## 範囲外(自動テストの対象外・手動確認)

- 確定字幕の右クリック(macOS: 2本指クリック / Control+クリック)で「辞書に登録…」メニューが出ること
- 既存ウィンドウが前面に出て、単語欄にフォーカスが入ること
- hf / qwen 以外のバックエンドではメニューが出ないこと
