# テスト設計: 確定字幕から辞書登録を開く

- 登録文の決定は純関数 `dict_prefill_text(state, uid)`(`main.py`)として UI 状態から検証する(`tests/test_caption_to_dict.py`)
- ウィンドウの一意性と単語欄の状態は、非表示の実 `tk.Tk` と一時 words.json を使って `DictLauncher`(`asr/dict_window.py`)を検証する(`tests/test_dict_launcher.py`)

### SPEC-009 確定字幕の登録文は、その発話の現在の表示テキスト(インライン編集後の文を含み、翻訳は含まない)である

- **TC-009-1** 発話2件 → 指定 uid の文が返る
- **TC-009-2** インライン編集(apply_edit)後 → 編集後の文が返る
- **TC-009-3** 翻訳付きの発話 → 翻訳を含まない原文だけが返る

### SPEC-010 存在しない発話を指定したとき、登録文は無い(None)

- **TC-010-1** 存在しない uid → None

### SPEC-011 辞書ウィンドウが開いていないときに開く操作をすると、辞書ウィンドウを1つ作る

- **TC-011-1** 初回 open → 生きた Toplevel を持つ DictWindow が返る

### SPEC-012 辞書ウィンドウが開いているときに開く操作をすると、新しいウィンドウを作らず既存のウィンドウを使う

- **TC-012-1** open を2回 → 同じ DictWindow が返り、root 直下の Toplevel は1つ

### SPEC-013 辞書ウィンドウを閉じた後に開く操作をすると、新しい辞書ウィンドウを作る

- **TC-013-1** open → そのウィンドウを destroy → open → 別の生きた DictWindow が返る

### SPEC-014 登録文を指定して開いたとき、単語欄はその登録文だけになり、全体が選択された状態になる

- **TC-014-1** 登録文付きで open → 単語欄がその文と一致し、選択範囲が先頭から末尾まで
- **TC-014-2** 単語欄に別の入力がある状態で、登録文付きで open → 単語欄は登録文だけ(元の入力は残らない)

### SPEC-015 登録文を指定せずに開いたとき、単語欄の入力は変わらない

- **TC-015-1** 単語欄に入力がある状態で、登録文なしで open → 単語欄は元の入力のまま
